# Tic-Tac-Toe AI

This project was developed as part of the CodSoft Artificial Intelligence Internship.

The objective of this project is to create an intelligent Tic-Tac-Toe game where a human player competes against an AI agent. The AI uses the Minimax Algorithm to evaluate possible moves and make optimal decisions.

## Features
- Human vs AI gameplay
- Minimax Algorithm implementation
- Winner and draw detection
- Interactive console interface
- Strategic AI decision-making

## Technologies Used
- Python
- Minimax Algorithm
- Game Theory
